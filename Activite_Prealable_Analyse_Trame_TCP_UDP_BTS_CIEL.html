PHASE 1 : Démonstration Enseignant & Décodage d'une Trame Brute (30 min)

1.1. Les Trames Échangées lors du Clic "Allumer" (GET /led/on)

Dans le TP WebServer, lorsque l'utilisateur clique sur le bouton "Allumer" (URL : http://192.168.1.100/led/on), le navigateur et le microcontrôleur échangent une suite précise de segments TCP :

   NAVIGATEUR CLIENT (PC)                                    SERVEUR EMBARQUÉ (XIAO / Pico W)
       IP: 192.168.1.50                                              IP: 192.168.1.100
       Port: 54321 (Éphémère)                                        Port: 80 (HTTP)
              |                                                             |
              | ================= PHASE A : 3-WAY HANDSHAKE =============== |
   [Trame 1]  | ------------ [SYN] Seq=0 ---------------------------------> |  1. Demande d'ouverture de session
   [Trame 2]  | <----------- [SYN, ACK] Seq=0, Ack=1 ---------------------- |  2. Acceptation & Synchronisation
   [Trame 3]  | ------------ [ACK] Seq=1, Ack=1 --------------------------> |  3. Acquittement final du client
              |                                                             |
              | ================= PHASE B : TRANSACTION HTTP ============== |
   [Trame 4]  | ------------ [PSH, ACK] GET /led/on HTTP/1.1 -------------> |  4. Requête Applicative (Clic)
   [Trame 5]  | <----------- [ACK] Seq=1, Ack=450 ------------------------- |  5. Acquittement TCP de réception
   [Trame 6]  | <----------- [PSH, ACK] HTTP/1.1 303 See Other ------------ |  6. Réponse serveur (Redirection '/')
   [Trame 7]  | ------------ [ACK] Seq=450, Ack=185 -----------------------> |  7. Acquittement client de la réponse
              |                                                             |
💡 Pourquoi 4 trames (ou 7 trames) selon le cas sous Wireshark ?
  • Cas A — Connexion persistante HTTP/1.1 (Keep-Alive) : Si la connexion TCP est déjà ouverte depuis le chargement de la page, la phase A (Handshake) est économisée. On observe alors exactement 4 trames : la requête [PSH, ACK], son [ACK], la réponse 303 See Other et son [ACK].
  • Cas B — Nouvelle connexion (fermeture après chaque requête) : Le 3-Way Handshake complet s'exécute obligatoirement avant d'acheminer la requête applicative HTTP, totalisant 7 trames.

1.2. Document Technique de Référence : Anatomie d'une Trame Ethernet Brute

Une trame réseau est constituée d'enveloppes emboîtées selon le principe d'encapsulation OSI :

+---------------------------------------------------------------------------------------------------------+
|                                    TRAME ETHERNET II (Couche 2 - Liaison)                                |
+-----------------------------------+---------------------------------------------------------------------+
| En-tête Ethernet (14 octets)     | Données Ethernet (Charge utile : Paquet IPv4)                       |
| [MAC Dest] [MAC Src] [Type=0800]  |                                                                     |
+-----------------------------------+---------------------------------------------------------------------+
                                    |                       PAQUET IPv4 (Couche 3 - Réseau)               |
                                    +-----------------------------------+---------------------------------+
                                    | En-tête IPv4 (20 octets)          | Données IP (Segment TCP)        |
                                    | [Ver/IHL] [Proto=06] [IP Src/Dst] |                                 |
                                    +-----------------------------------+---------------------------------+
                                                                        |       SEGMENT TCP (Couche 4)    |
                                                                        +-------------------+-------------+
                                                                        | En-tête TCP (20o) | Payload L7  |
                                                                        | [Ports] [Flags]   | "GET ..."   |
                                                                        +-------------------+-------------+

1.3. Documents Techniques Ressources pour l'Étudiant

📖 Document Ressource A : Extrait RFC 791 / IANA — Table des Protocoles IPv4 (Offset 0x17)

Dans l'en-tête IPv4, l'octet situé à l'offset 0x17 (23 en décimal) indique à quel protocole de couche transport (L4) les données doivent être délivrées :

Valeur Décimale Valeur Hexa Sigle Protocole Nom & Rôle Applicatif usuel
1 0x01 ICMP Internet Control Message Protocol (Commandes Ping, messages d'erreurs réseau)
2 0x02 IGMP Internet Group Management Protocol (Gestion des groupes Multicast)
6 0x06 TCP Transmission Control Protocol (Mode connecté, fiable : HTTP, HTTPS, SSH, MQTT)
17 0x11 UDP User Datagram Protocol (Mode non connecté, rapide : DNS, DHCP, NTP, Télémétrie)
41 0x29 IPv6 Encapsulation de paquets IPv6 dans IPv4 (Tunnel 6in4)
89 0x59 OSPF Open Shortest Path First (Protocole de routage dynamique)

Note de conversion : 17 en base 10 = (1 × 16) + 1 = 0x11 en hexadécimal. 6 en base 10 = 0x06.

📖 Document Ressource B : Extrait RFC 793 / 9293 — Registre des Drapeaux TCP (Offset 0x2F)

L'octet situé à l'offset 0x2F (47 en décimal) contient les 8 bits de contrôle gouvernant le cycle de vie de la session TCP :

Bit 7 Bit 6 Bit 5 Bit 4 Bit 3 Bit 2 Bit 1 Bit 0
CWR ECE URG ACK PSH RST SYN FIN
Congestion Reduced ECN Echo Pointeur Urgent Acquittement Push Function Reset Connexion Synchronisation Fin de session
Poids : 128 (0x80) Poids : 64 (0x40) Poids : 32 (0x20) Poids : 16 (0x10) Poids : 8 (0x08) Poids : 4 (0x04) Poids : 2 (0x02) Poids : 1 (0x01)

Rôle technique des principaux drapeaux :

  • SYN (0x02) : Utilisé lors du handshake pour synchroniser les numéros de séquence initiaux.
  • ACK (0x10) : Indique que le champ Acknowledgment Number est valide et confirme la réception d'octets.
  • PSH (Push - 0x08) : Indicateur de vidage forcé. Par défaut, pour optimiser la bande passante (algorithme de Nagle), la couche TCP peut temporiser et agréger plusieurs octets dans son tampon avant de les transmettre. Le drapeau PSH ordonne à la pile réceptrice de transmettre immédiatement les données à l'application sans attendre le remplissage complet du tampon (MSS). Pour une commande HTTP GET /led/on, c'est indispensable pour déclencher l'action sans latence !
  • FIN (0x01) : Indique que l'émetteur a terminé de transmettre ses données et demande la fermeture de session.

2.2. Téléversement du Firmware Double Écoute sur votre Microcontrôleur

Fichier Arduino : xiao_dual_http_udp_led.ino (À flasher par le binôme) Étape Pratique 1 
/* ====================================================================
   BTS CIEL - TP Communications Wi-Fi Avancées
   Firmware à Double Écoute : Serveur Web HTTP (TCP 80) & Socket UDP (4210)
   Compatible : Seeed Studio XIAO ESP32-S3 / C3 & Raspberry Pi Pico W
   ==================================================================== */
#include <WiFi.h>
#include <WiFiUdp.h>
#include <WebServer.h>

#if defined(ARDUINO_ARCH_RP2040)
  const int PIN_LED = LED_BUILTIN;
#elif defined(ESP32)
  const int PIN_LED = 21; // XIAO ESP32-S3 (Active LOW)
#endif

// Renseignez le SSID et mot de passe de la salle de TP :
const char* SSID     = "WIFI_SALLE_CIEL";
const char* PASSWORD = "SuperSecretCIEL2026";

WebServer server(80);          // Serveur Web HTTP sur TCP Port 80
WiFiUDP udp;                   // Socket UDP
const uint16_t UDP_PORT = 4210;// Écoute UDP sur Port 4210

char udpBuffer[64];

void allumerLED() {
#if defined(ESP32)
  digitalWrite(PIN_LED, LOW);  // Allumé pour XIAO ESP32-S3
#else
  digitalWrite(PIN_LED, HIGH); // Allumé pour Pico W
#endif
}

void eteindreLED() {
#if defined(ESP32)
  digitalWrite(PIN_LED, HIGH); // Éteint
#else
  digitalWrite(PIN_LED, LOW);  // Éteint
#endif
}

// --- Gestionnaires de routes HTTP (Voie TCP 80) ---
void handleRoot() {
  String html = "<!DOCTYPE html><html><head><meta charset='utf-8'>";
  html += "<title>Test TCP vs UDP - BTS CIEL</title><style>";
  html += "body{font-family:Arial;text-align:center;margin-top:40px;background:#f0f4f8;}";
  html += ".btn{padding:14px 28px;font-size:18px;margin:10px;border-radius:6px;border:none;color:white;cursor:pointer;}";
  html += ".on{background:#22c55e;} .off{background:#ef4444;}</style></head><body>";
  html += "<h1>Contrôle LED (Voie Web HTTP - Port TCP 80)</h1>";
  html += "<p>Chaque clic génère un Handshake TCP + Requête + Réponse</p>";
  html += "<a href='/led/on'><button class='btn on'>Allumer (HTTP / TCP)</button></a>";
  html += "<a href='/led/off'><button class='btn off'>Éteindre (HTTP / TCP)</button></a>";
  html += "</body></html>";
  server.send(200, "text/html", html);
}

void handleLedOn() {
  allumerLED();
  Serial.println("[TCP/HTTP] Requête reçue : /led/on -> LED ALLUMEE");
  server.sendHeader("Location", "/");
  server.send(303); // Redirection HTTP
}

void handleLedOff() {
  eteindreLED();
  Serial.println("[TCP/HTTP] Requête reçue : /led/off -> LED ETEINTE");
  server.sendHeader("Location", "/");
  server.send(303);
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED, OUTPUT);
  eteindreLED();

  WiFi.mode(WIFI_STA);
  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) { delay(200); Serial.print("."); }

  Serial.println("\n[OK] Connecté au Wi-Fi.");
  Serial.print("Adresse IP de votre carte : "); Serial.println(WiFi.localIP());

  // Démarrage Serveur HTTP (TCP)
  server.on("/", handleRoot);
  server.on("/led/on", handleLedOn);
  server.on("/led/off", handleLedOff);
  server.begin();
  Serial.println("[OK] Serveur Web HTTP actif sur Port 80 (TCP)");

  // Démarrage Écoute UDP
  udp.begin(UDP_PORT);
  Serial.print("[OK] Serveur UDP à l'écoute sur Port "); Serial.println(UDP_PORT);
}

void loop() {
  // 1. Écoute client Web HTTP (TCP)
  server.handleClient();

  // 2. Écoute datagrammes UDP directs
  int packetSize = udp.parsePacket();
  if (packetSize > 0) {
    int len = udp.read(udpBuffer, sizeof(udpBuffer) - 1);
    if (len > 0) udpBuffer[len] = '\0';

    Serial.print("[UDP Datagramme REÇU] Message : ");
    Serial.print(udpBuffer);
    Serial.print(" | Taille : "); Serial.print(packetSize); Serial.println(" octets");

    if (strstr(udpBuffer, "ON") != NULL) {
      allumerLED();
    } else if (strstr(udpBuffer, "OFF") != NULL) {
      eteindreLED();
    }
  }
}

import socket, tkinter as tk

# ⚠️ Remplacer par l'IP de votre propre carte !
TARGET_IP, UDP_PORT = "192.168.1.100", 4210
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
