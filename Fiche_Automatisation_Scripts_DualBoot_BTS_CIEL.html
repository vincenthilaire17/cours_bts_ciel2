01 Déploiement par le Réseau : Possibilités et Limites Techniques

Question fréquente en atelier : « Si tous mes postes sont sur le même sous-réseau (ex : 192.168.1.0/24), est-il possible de voir les machines et d'injecter directement le Dual-Boot à distance ? »

Les 3 verrous d'un déploiement 100% à distance sous Windows standard
  1. Verrou du noyau Windows en fonctionnement : Un système d'exploitation ne peut pas partitionner et formater une partition ext4 pour y injecter un noyau Linux natif pendant qu'il est lui-même en train de s'exécuter. Il faut nécessairement que l'ordinateur s'amorce sur un environnement Linux (via clé USB ou PXE).
  2. Absence de WinRM / SSH par défaut : Sur Windows 11 Famille, la gestion à distance PowerShell (WinRM) et les partages d'administration (`ADMIN$`) sont désactivés pour des raisons de sécurité grand public.
  3. Verrou de sécurité matériel (TPM 2.0 / BitLocker) : La modification de la table des partitions modifie les registres de mesures (PCR) du TPM 2.0, ce qui déclenche une demande de validation de sécurité au reboot.

La solution optimale en atelier BTS : Combiner un **script de préparation automatique sous Windows 11** (1-clic) avec le **script de configuration GRUB sous Ubuntu**, permettant de préparer et finaliser un parc de 15 à 30 machines en un temps record.

02 Préparation de la Clé USB : Faut-il juste copier l'ISO ?

Règle fondamentale
Non, un simple copier-coller du fichier .iso sur une clé USB standard ne fonctionne pas. Le BIOS/UEFI de la carte mère ne peut pas exécuter un fichier ISO stocké comme un simple fichier de données. La clé doit posséder un secteur d'amorçage EFI.
Outil Principe de fonctionnement Mode opératoire recommandé
Rufus
(Méthode industrielle)		 Décompresse l'ISO et écrit directement les partitions EFI et ext4 sur la clé. 1. Sélectionner l'ISO d'Ubuntu.
2. Schéma de partition : GPT.
3. Système de destination : UEFI (non CSM).
4. Cliquer sur Démarrer (mode Image ISO).
Ventoy
(Méthode multi-ISO)		 Installe un chargeur UEFI sur la clé qui permet ensuite de glisser-déposer simplement les fichiers ISO. 1. Installer Ventoy une fois sur la clé via Ventoy2Disk.exe.
2. Copier-coller directement le fichier .iso d'Ubuntu sur la clé comme un document standard.

03 Script 1 : Préparation Automatique sous Windows 11

Ce script prépare la machine en moins de 30 secondes sans aucune manipulation manuelle dans la Gestion des disques :

Windows 11 Fonctionnalités automatisées par preparer_dualboot_windows11.ps1
  • Auto-élévation UAC : Si l'utilisateur double-clique sans droits admin, le script s'auto-relance avec élévation.
  • Désactivation du Démarrage Rapide : Écrit HiberbootEnabled = 0 dans le registre et exécute powercfg /h off pour libérer le fichier verrouillé hiberfil.sys.
  • Protection BitLocker / Chiffrement OEM : Détecte si le volume C: est chiffré, sauvegarde la clé de secours à 48 chiffres dans un fichier texte sur le Bureau, et suspend la protection pour 2 redémarrages (évite l'écran bleu TPM).
  • Partitionnement automatique : Calcule la taille et réduit le volume C: de 102 400 Mo (100 Go) pour générer l'espace noir « Non alloué » prêt pour Ubuntu.

Comment l'exécuter en 1 clic :

Faites simplement un clic droit > « Exécuter en tant qu'administrateur » sur le fichier :
LANCER_PREPARATION_DUALBOOT.bat (qui contient : powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%~dp0preparer_dualboot_windows11.ps1").

04 Script 2 : Paramétrage Automatique de GRUB sous Ubuntu

Après avoir installé Ubuntu sur les 100 Go libres, ouvrez le terminal (Ctrl + Alt + T) et lancez : 

etudiant@pc-ciel-01:~$ sudo bash configurer_grub_dualboot.sh
Ubuntu Linux Actions réalisées par configurer_grub_dualboot.sh
  • Sauvegarde de secours automatique du fichier original dans /etc/default/grub.backup.*.
  • Installation et exécution automatique de os-prober pour détecter Windows 11.
  • Réglage de la temporisation : GRUB_TIMEOUT=10 (10 secondes chrono).
  • Affichage visible du menu : GRUB_TIMEOUT_STYLE=menu.
  • Menu interactif demandant l'OS par défaut (1 = Windows 11, 2 = Ubuntu, 3 = Mémoriser le dernier).
  • Régénération immédiate via update-grub.

05 Procédure Express pour Déployer une Salle Complète

Phase Action à mener sur chaque poste Temps estimé
1. Préparation Windows Insérer la clé USB d'outils, double-cliquer sur LANCER_PREPARATION_DUALBOOT.bat. 30 secondes
2. Boot & Install Ubuntu Redémarrer (F12/F9/F8), choisir la clé UEFI, installer sur l'espace libre de 100 Go. 6 à 10 minutes
3. Finalisation GRUB Ouvrir la session Ubuntu, exécuter sudo bash configurer_grub_dualboot.sh. 20 secondes
