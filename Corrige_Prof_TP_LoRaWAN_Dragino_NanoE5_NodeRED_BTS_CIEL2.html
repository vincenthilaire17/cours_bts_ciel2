🛠️ Préparation Enseignant Avant la Séance (≈ 45 min)
  1. Serveur réseau LoRaWAN (ChirpStack v4) : Démarré sur une machine du réseau pédagogique (dépôt Docker officiel chirpstack-docker avec ChirpStack + gateway-bridge UDP 1700 + broker Mosquitto 1883 + PostgreSQL + Redis). Activer la région eu868. Vérifier que les ports 8080/tcp, 1700/udp et 1883/tcp sont ouverts.
  2. Profil d'équipement : Région EU868, LoRaWAN 1.0.3, Regional parameters revision A, classe A, activation OTAA. Créer une application unique (ex. lycee-lora).
  3. Passerelle Dragino LPS8v3 (EU868, option 4G EC25) : Connectée en Ethernet au réseau local, IP fixe ou DHCP réservée. Noter son Gateway EUI et la déclarer dans ChirpStack. Vérifier le mot de passe administrateur (ne pas laisser le mot de passe usine).
  4. Fiches binômes : Pré-générer des AppKeys aléatoires de 32 caractères hexadécimaux pour chaque binôme et assigner des noms d'équipements distincts (groupe-1, groupe-2, etc.).
  5. Câbles de mesure de courant : Préparer des cordons USB avec le fil rouge (+5V) coupé et rebouclé par la résistance de précision 1,1 Ω (kit TI myParts), avec sorties dénudées pour les pointes 1+ et 1− de l'AD3.
⚠️ Pièges Fréquents & Dépannage Rapide en Séance
  1. Le modem ne répond pas à AT dans le pont série :
    • Termineur de ligne du Moniteur Série mal réglé : il faut impérativement choisir « NL et CR » / Both NL & CR (le firmware Wio-E5 attend \r\n).
    • Inversion RX/TX : sur le port Grove D2, D2 est relié au TX du modem (Nano RX) et D3 au RX du modem (Nano TX). Tester SoftwareSerial lora(3, 2); si besoin.
  2. Échec du Join OTAA (+JOIN: Join failed) :
    • Erreur de recopie du DevEUI (16 hex) ou de l'AppKey (32 hex) dans ChirpStack.
    • Passerelle hors ligne ou non vue par le serveur (vérifier Last seen dans ChirpStack).
    • Oubli de l'antenne 868 MHz sur le module Grove LoRa-E5.
  3. Powerbank qui s'éteint toute seule : De nombreux accumulateurs modernes intègrent une coupure automatique si le courant appelé passe sous 50–100 mA. Pendant les phases de veille du Nano (≈ 30 mA), la Powerbank peut se couper. Solution : ajouter une résistance de charge permanente ou alimenter via un port USB secouru.

1. Code de Référence Sketch 1 — Pont Série AT (MultiSerial)

Ce programme permet l'audit et la configuration interactive du modem Grove LoRa-E5 via la console USB du PC.

📄 Pont_AT_LoRaE5.ino — Code Enseignant Complet
/*
 * TP LoRaWAN BTS CIEL 2 - Sketch 1 : Pont Serie de Configuration AT
 * Cible : Arduino Nano v3 (ATmega328P 5V) + Platine Grove + Grove LoRa-E5 (Wio-E5)
 * Cablage : Port Grove D2 (D2 = Nano RX <- TX LoRa, D3 = Nano TX -> RX LoRa)
 */

#include <SoftwareSerial.h>

const uint8_t LORA_RX_PIN = 2; // Nano RX <- LoRa TX
const uint8_t LORA_TX_PIN = 3; // Nano TX -> LoRa RX

SoftwareSerial loraSerial(LORA_RX_PIN, LORA_TX_PIN);

void setup() {
  Serial.begin(9600);
  while (!Serial); // Attente énumération USB

  loraSerial.begin(9600); // Vitesse usine par defaut du firmware LoRa-E5 AT

  Serial.println(F("============================================================"));
  Serial.println(F("  BTS CIEL 2 - Pont Serie AT Arduino Nano <-> Grove LoRa-E5 "));
  Serial.println(F("  Vitesse : 9600 bauds. Regler le terminal sur 'Both NL & CR' "));
  Serial.println(F("  Commandes utiles :                                          "));
  Serial.println(F("    AT+VER         -> Version firmware                        "));
  Serial.println(F("    AT+ID          -> DevEUI, AppEUI (JoinEUI), DevAddr       "));
  Serial.println(F("    AT+MODE=LWOTAA -> Mode LoRaWAN OTAA                       "));
  Serial.println(F("    AT+DR=EU868    -> Region Europe 868 MHz                   "));
  Serial.println(F("============================================================"));
}

void loop() {
  // Transfert PC -> LoRa-E5
  if (Serial.available()) {
    char c = Serial.read();
    loraSerial.write(c);
  }

  // Transfert LoRa-E5 -> PC
  if (loraSerial.available()) {
    char c = loraSerial.read();
    Serial.write(c);
  }
}

2. Code de Référence Sketch 2 — Nœud LoRaWAN Autonome Complet

Ce programme assure l'acquisition analogique de la température (relation de Steinhart-Hart B=4275), la mesure interne de la tension Vcc (bandgap 1,1 V), le formatage de la charge utile de 5 octets en Big-Endian et l'émission périodique toutes les 60 secondes.

📄 LoRa_Noeud_Nano_E5.ino — Code Enseignant Complet
/*
 * TP LoRaWAN BTS CIEL 2 - Sketch 2 : Noeud Autonome de Telemetrie Campus
 * Cible : Arduino Nano v3 (ATmega328P 5V) + Grove LoRa-E5 + Capteur Temperature Grove v1.2
 *
 * Cablage :
 *   - Grove LoRa-E5 sur port Grove D2 (RX=D2, TX=D3)
 *   - Capteur de Temperature Grove v1.2 sur port Grove A0
 *
 * Trame binaire compacte emise (5 octets) :
 *   [0..1] : Temperature signee x10 (int16_t, MSB first) -> 245 = 24.5 deg C
 *   [2..3] : Tension Vcc en mV (uint16_t, MSB first)       -> 5002 = 5.002 V
 *   [4]    : Compteur d'emission (uint8_t, 0 a 255)
 */

#include <SoftwareSerial.h>

const uint8_t LORA_RX_PIN = 2; // D2 = RX Nano (TX LoRa-E5)
const uint8_t LORA_TX_PIN = 3; // D3 = TX Nano (RX LoRa-E5)
SoftwareSerial lora(LORA_RX_PIN, LORA_TX_PIN);

const uint8_t TEMP_PIN = A0;
const int B_COEFFICIENT = 4275; // Parametre B thermistance Grove v1.2
const long R0 = 100000;         // R0 = 100 kOhm a 25 deg C

// Cle d'application LoRaWAN OTAA (16 octets = 32 caracteres hexadécimaux)
const char APPKEY[] = "2B7E151628AED2A6ABF7158809CF4F3C"; 

uint8_t packetCounter = 0;

// Envoi d'une commande AT et verification de la reponse avec timeout
bool sendATCommand(const char* cmd, const char* expectedResponse, unsigned long timeoutMs = 5000) {
  lora.print(cmd);
  lora.print("\r\n");
  
  unsigned long start = millis();
  String response = "";
  while (millis() - start < timeoutMs) {
    while (lora.available()) {
      char c = lora.read();
      response += c;
    }
    if (response.indexOf(expectedResponse) != -1) {
      Serial.print(F("[LoRa-E5] "));
      Serial.println(response);
      return true;
    }
  }
  Serial.print(F("[TIMEOUT/ERR] Cmd: "));
  Serial.print(cmd);
  Serial.print(F(" | Rep: "));
  Serial.println(response);
  return false;
}

// Mesure de la tension d'alimentation interne Vcc via la reference 1.1V interne de l'ATmega328P
uint16_t readVccMillivolts() {
  #if defined(__AVR_ATmega328P__) || defined(__AVR_ATmega168__)
    ADMUX = _BV(REFS0) | _BV(MUX3) | _BV(MUX2) | _BV(MUX1);
  #elif defined(__AVR_ATmega32U4__)
    ADMUX = _BV(REFS0) | _BV(MUX4) | _BV(MUX3) | _BV(MUX2) | _BV(MUX1);
  #else
    return 5000;
  #endif
  delay(3); // Stabilisation du convertisseur
  ADCSRA |= _BV(ADSC); // Lancement conversion
  while (bit_is_set(ADCSRA, ADSC));
  uint8_t low  = ADCL;
  uint8_t high = ADCH;
  long result = (high << 8) | low;
  result = 1125300L / result; // Calcul : Vcc = 1.1V * 1023 * 1000 / ADC
  return (uint16_t)result;
}

// Mesure et conversion de la temperature du capteur Grove (deg C x 10)
int16_t readTemperatureDecicelsius() {
  int rawADC = analogRead(TEMP_PIN);
  if (rawADC <= 0) rawADC = 1;
  if (rawADC >= 1023) rawADC = 1022;
  
  // Calcul resistance thermistance CTN
  float R = 1023.0 / rawADC - 1.0;
  R = 100000.0 * R;
  
  // Equation de Steinhart-Hart simplifiee (parametre B)
  float temperatureC = 1.0 / (log(R / 100000.0) / B_COEFFICIENT + 1.0 / 298.15) - 273.15;
  
  return (int16_t)(temperatureC * 10.0 + (temperatureC >= 0 ? 0.5 : -0.5));
}

void setup() {
  Serial.begin(9600);
  while (!Serial);
  lora.begin(9600);

  Serial.println(F("\n========================================================"));
  Serial.println(F("  Initialisation du Noeud LoRaWAN - BTS CIEL 2           "));
  Serial.println(F("========================================================"));

  // 1. Test communication
  sendATCommand("AT", "+AT: OK", 2000);

  // 2. Configuration LoRaWAN OTAA Europe 868 MHz
  sendATCommand("AT+MODE=LWOTAA", "+MODE: LWOTAA", 2000);
  sendATCommand("AT+DR=EU868", "+DR: EU868", 2000);
  sendATCommand("AT+CLASS=A", "+CLASS: A", 2000);

  // 3. Configuration de la cle d'application (AppKey)
  char cmdKey[64];
  snprintf(cmdKey, sizeof(cmdKey), "AT+KEY=APPKEY,\"%s\"", APPKEY);
  sendATCommand(cmdKey, "+KEY: APPKEY", 2000);

  // 4. Procedure de Join OTAA (Association au reseau)
  Serial.println(F("Tentative de JOIN OTAA en cours... (patientez jusqu'a 25s)"));
  bool joined = false;
  for (int attempt = 1; attempt <= 3; attempt++) {
    Serial.print(F("Tentative ")); Serial.print(attempt); Serial.println(F("/3..."));
    if (sendATCommand("AT+JOIN", "+JOIN: Done", 25000)) {
      joined = true;
      Serial.println(F(">> Nœud associe avec succes au reseau LoRaWAN !"));
      break;
    }
    delay(5000);
  }

  if (!joined) {
    Serial.println(F(">> ALERTE : Echec du Join OTAA. Verifiez passerelle et identifiants."));
  }
}

void loop() {
  int16_t tempDeciC = readTemperatureDecicelsius();
  uint16_t vccMilliV = readVccMillivolts();
  packetCounter++;

  Serial.print(F("\n[Trame #")); Serial.print(packetCounter); Serial.println(F("]"));
  Serial.print(F("  Temperature : ")); Serial.print(tempDeciC / 10.0, 1); Serial.println(F(" deg C"));
  Serial.print(F("  Tension Vcc : ")); Serial.print(vccMilliV / 1000.0, 3); Serial.println(F(" V"));

  // Encodage binaire en hexadecimal Big-Endian (5 octets = 10 caracteres hex)
  char hexPayload[16];
  snprintf(hexPayload, sizeof(hexPayload), "%04X%04X%02X",
           (uint16_t)tempDeciC,
           vccMilliV,
           packetCounter);

  Serial.print(F("  Payload HEX : ")); Serial.println(hexPayload);

  // Envoi LoRaWAN sans acquittement (Unconfirmed Data Up)
  char sendCmd[40];
  snprintf(sendCmd, sizeof(sendCmd), "AT+MSGHEX=\"%s\"", hexPayload);
  sendATCommand(sendCmd, "+MSGHEX: Done", 12000);

  // Cadence d'emission : 60 secondes (Duty-Cycle 1%)
  Serial.println(F("Attente 60 secondes avant prochaine emission..."));
  delay(60000);
}

let pl = msg.payload;

  try { pl = JSON.parse(pl); } catch(e) { return null; }

  devEui: devEui,

return msg;

📝 Corrigé Détaillé des Questions & Tableaux

Partie 0 : Analyse Comparative & Choix LoRaWAN

✅ Corrigé Q0.1 & Q0.2
  • Q0.1 — Justification du choix pour le local éloigné :
    • Portée : LoRaWAN offre 2 à 5 km en environnement urbain/bâti contre 30 à 100 m pour le Wi-Fi et 10 à 100 m pour le BLE. Il traverse aisément les murs épais du lycée.
    • Autonomie : Consommation en veille de quelques microampères (≈ 2 μA pour le modem), permettant plusieurs mois à années sur accumulateur, là où le Wi-Fi (100 à 300 mA continus) vide une batterie en quelques heures.
    • Coût d'infrastructure : Réseau privé gratuit sans abonnement ni carte SIM (contrairement à la 4G qui requiert un forfait mensuel récurrent par capteur). Une seule passerelle couvre tout le site.
    • Inconvénient à accepter : Débit très faible (0,3 à 5,5 kbit/s), messages restreints (petits volumes de données), impossibilité de faire du streaming vidéo ou de l'envoi de gros fichiers, latence en Classe A.
  • Q0.2 — Analyse du passage SF7 → SF12 :
    • La durée d'émission passe de 51,5 ms à 1 319 ms, soit une multiplication par un facteur de 25,6 (1319 / 51,5).
    • En échange, le récepteur gagne 14 dB de sensibilité (−123 dBm → −137 dBm), ce qui double la portée radio pratique en espace libre.
    • L'énergie consommée par trame étant le produit de la puissance par le temps (E = P × t), elle est multipliée par ≈ 25 : le nœud épuise sa batterie 25 fois plus vite par message émis.
    • L'intervalle minimal réglementaire imposé par le Duty-Cycle de 1 % passe de 5,2 s en SF7 à 132 s en SF12 (1 319 ms × 100).

  • Q1.1 — Non : La passerelle ne déchiffre pas les mesures de température car elle ne possède pas la clé applicative (AppSKey). Elle est qualifiée de « transparente » car elle se contente d'encapsuler la trame radio brute dans un paquet IP/UDP vers le serveur sans en interpréter le contenu.

Si un paquet est perdu, TCP bloquerait les flux suivants. Les informations ajoutées par la passerelle sont : le RSSI (puissance reçue en dBm), le SNR (rapport signal sur bruit en dB), la fréquence radio exacte, le timestamp UTC et le Gateway EUI.
  • Q1.3 — Démarche de diagnostic méthodique :
    1. Couche physique & IP : Vérifier la LED SYS (bleue fixe) et s'assurer que la passerelle obtient une adresse IP valide (ping depuis le PC).
    2. Configuration packet forwarder : Vérifier dans l'interface Dragino que l'IP du serveur ChirpStack et le port UDP 1700 sont correctement saisis, et que le Gateway ID correspond exactement au Gateway EUI.
    3. Côté serveur ChirpStack : Vérifier que le service chirpstack-gateway-bridge est actif et que le pare-feu du serveur autorise les paquets entrants sur 1700/udp.

  • Q2.1 — Le DevEUI (Device Extended Unique Identifier) sur 64 bits (16 caractères hex) est l'équivalent de l'adresse MAC Ethernet. Il est unique au monde et permet au serveur d'identifier de manière certaine le nœud émetteur.
  • Q2.2 — Décodage manuel de la trame 00 F5 13 8A 07 :
    • 00 F5 (16 bits) = 0 × 256 + 245 = 245 dixièmes de °C → +24,5 °C.
    • 13 8A (16 bits) = 19 × 256 + 138 = 4 864 + 138 = 5 002 mV (5,002 V).
    • 07 (8 bits) = Trame n° 7.
    • Cas FF EC : FF EC en hexadécimal vaut 65 516 en non signé. En signé (complément à 2 sur 16 bits) : 65 516 − 65 536 = −20 dixièmes de °C → −2,0 °C.
  • Q2.3 — Efficacité spectrale (Binaire vs ASCII) : Le message texte "24.5;5.00;7" fait 11 octets au lieu de 5 octets. Avec l'en-tête LoRaWAN (13 octets), la trame passe de 18 octets à 24 octets sur le canal radio. La durée d'émission augmente d'environ 20 %, ce qui consomme 20 % d'énergie supplémentaire sur la batterie et réduit le nombre de messages autorisés par heure par le Duty-Cycle de 1 %.

  • Q4.1 — Causes d'incertitude métrologique : Tolérance de la résistance de shunt (généralement ±5 % sur 1,1 Ω), temps de réveil et de stabilisation du PLL de l'émetteur radio avant l'émission des préambules, bruit de commutation du convertisseur de la Powerbank, résolution des curseurs WaveForms à l'écran.
  • Q4.2 — Calcul d'autonomie (Exemple avec batterie 5 000 mAh utile à 70 % = 3 500 mAh) :
    • En SF7 (tTX = 0,0515 s, Iveille = 35 mA, ITX = 95 mA) :
      Imoy = 35 + (95 − 35) × (0,0515 / 60) = 35 + 0,0515 = 35,05 mA.
      Autonomie = 3 500 / 35,05 ≈ 99,8 heures (≈ 4,1 jours).
    • En SF12 (tTX = 1,319 s) :
      Imoy = 35 + (95 − 35) × (1,319 / 60) = 35 + 1,319 = 36,32 mA.
      Autonomie = 3 500 / 36,32 ≈ 96,3 heures (≈ 4,0 jours).
    • Analyse cruciale : La radio ne représente que 0,15 % du courant moyen en SF7 et 3,6 % en SF12 ! L'essentiel de l'énergie est gaspillé par l'Arduino Nano et le régulateur restés allumés en veille (Iveille = 35 mA). En mettant l'ATmega328P en veille profonde PWR_DOWN et le modem en veille AT+LOWPOWER, Iveille chute à moins de 20 μA, propulsant l'autonomie à plus de 5 ans !
  • Q4.3 — Synthèse et choix pour image VGA toutes les 10 s :
    • Avantages LoRaWAN démontrés : Portée kilométrique traversant les bâtiments, réseau privé gratuit sans abonnement, très faible énergie par trame émise.
    • Limites : Débit bridé (max 5,5 kbit/s), taille de charge limitée à quelques dizaines d'octets, Duty-Cycle ≤ 1 % interdisant les cadences rapides.
    • Pour une image VGA (640×480 ≈ 50 à 150 Ko JPEG) toutes les 10 s : Choisir impérativement le Wi-Fi (ou la 4G/5G). LoRaWAN est physiquement incapable de transmettre 100 Ko en 10 secondes (cela violerait la loi du Duty-Cycle et prendrait plusieurs dizaines de minutes de transmission continue).
